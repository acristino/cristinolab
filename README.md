# cristinolab.com

Official homepage of the Neurogenomics and Systems Biology Laboratory (Cristino Lab), GRIDD, Griffith University.

## Structure
- `index.html` — main homepage
- `assets/img/` — images and logo
- `assets/css/` — stylesheets (future)
- `assets/js/` — scripts (future)

## Deployment
Pushes to `main` auto-deploy to GoDaddy via GitHub Actions.
