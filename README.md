# cristinolab.com

Official homepage of the Neurogenomics and Systems Biology Laboratory (Cristino Lab), Institute for Biomedicine and Glycomics (IBG), Griffith University.

## Site structure

| File | Description |
|---|---|
| `index.html` | Home — hero, image gallery, lab overview |
| `about.html` | PI profile, biography, grants & funding |
| `research.html` | Research areas (Basic & Medical) |
| `team.html` | Current members, supervision history, alumni |
| `publications.html` | All 49 publications with syntheses and word cloud |
| `collaborations.html` | IBG/Griffith, national and international partners |
| `resources.html` | Resources (coming soon) |
| `tools.html` | Bioinformatics tools (coming soon) |
| `contact.html` | Contact details and opportunities |

## Assets

| Path | Contents |
|---|---|
| `assets/css/style.css` | Shared stylesheet for all pages |
| `assets/img/` | Team photos, lab images, logo |
| `assets/js/` | Scripts (future) |

## Deployment

Pushes to `main` auto-deploy to [cristinolab.com](https://cristinolab.com) via Cloudflare Pages.

## Local preview

Open any HTML file directly in a browser — no build step or server required.

```bash
# Or serve locally for accurate font loading
python3 -m http.server 8080
```
